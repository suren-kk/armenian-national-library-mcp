# Contributing

Thank you for considering a contribution to this independent research project.

## Before submitting

- Keep the server provider-neutral, public-read, and unofficial.
- Do not add NLA logos, claim NLA endorsement, or describe project output as a rights determination.
- Do not commit credentials, personal data, full document text, file bytes, or copyrighted fixtures unless their inclusion and licence have been explicitly reviewed.
- Use synthetic or minimally necessary sanitized fixtures.
- Preserve copyright, licence, attribution, privacy, and access-status fields rather than inventing or discarding them.
- Run `npm run ci` before opening a pull request.

## Developer Certificate of Origin

This project uses the [Developer Certificate of Origin 1.1](https://developercertificate.org/) instead of a contributor licence agreement. Add a sign-off to every commit:

```text
Signed-off-by: Your Name <your-email@example.com>
```

Use `git commit -s` to add it automatically. By signing off, you certify that you have the right to submit the contribution under the project's MIT License and the terms of the Developer Certificate of Origin. The sign-off name and email become part of the public Git history.

## Third-party material

Identify copied or adapted code, schemas, documentation, generated assets, and test data in the pull request. Include the source, version, copyright notice, licence, and any required attribution. Do not submit material under terms incompatible with the MIT-licensed project or with public distribution.

## Reporting sensitive issues

Do not put vulnerabilities, private personal information, or non-public rights complaints in a public issue. Follow [SECURITY.md](SECURITY.md), [PRIVACY.md](PRIVACY.md), or [TAKEDOWN.md](TAKEDOWN.md), as appropriate.
