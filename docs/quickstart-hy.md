# Արագ մեկնարկ (հայերեն)

`armenian-national-library-mcp`-ն Հայաստանի ազգային գրադարանի հանրային DSpace շտեմարանի համար նախատեսված անկախ և ոչ պաշտոնական, միայն ընթերցման MCP սերվեր է։ Այն չի ստեղծվել և չի սպասարկվում Հայաստանի ազգային գրադարանի կողմից։

## Տեղային տեղադրում

Փաթեթը դեռ հրապարակված չէ npm-ում, ուստի այժմ օգտագործեք սկզբնական կոդը․

```bash
git clone https://github.com/suren-kk/armenian-national-library-mcp.git
cd armenian-national-library-mcp
npm install
cp .env.example .env
npm run ci
npm run build
```

Codex-ի կամ Claude-ի MCP կարգավորումներում գործարկեք՝

```json
{
  "command": "node",
  "args": ["/բացարձակ/ուղի/armenian-national-library-mcp/dist/index.js"]
}
```

## Փորձնական հարցումներ

- «Գտիր Հովհաննես Թումանյանի ստեղծագործությունները և նշիր գրադարանի սկզբնաղբյուրները»։
- «Գտիր Հայաստանի պատմության վերաբերյալ նյութեր և ճշտիր որոնումն ըստ թեմայի»։
- «Ցույց տուր ընտրված գրառման ամբողջական մետատվյալները և օգտագործման իրավունքների մասին առկա տվյալները»։

Եթե առկա է հանրային `TEXT` փաթեթ, սերվերը կարող է վերադարձնել տեքստը սահմանափակ հատվածներով։ Հաջորդ հատվածի համար `nextOffset` արժեքը փոխանցեք որպես `offset_chars`։ Եթե տեքստ չկա, օգտագործեք մետատվյալները և, հասանելիության դեպքում, բնօրինակ ֆայլի NLA հղումը։

## Կարևոր սահմանափակումներ

- Հանրային հասանելիությունը չի նշանակում ազատ վերօգտագործման, հրապարակման կամ առևտրային օգտագործման թույլտվություն։ Ստուգեք աղբյուրում նշված իրավունքները։
- Սերվերը տեղային PDF տեքստի ճանաչում կամ OCR չի կատարում։
- Որոնման հարցումները և նույնացուցիչները ուղարկվում են `api.nla.am`, իսկ ձեր MCP հաճախորդը կարող է արդյունքը փոխանցել ձեր ընտրած AI ծառայությանը։
- Մի հրապարակեք գաղտնաբառեր, նշաններ, լիարժեք փաստաթղթեր կամ ներբեռնված ֆայլեր GitHub issue-ում։

Խնդիրների դեպքում տեսեք [աջակցության ուղեցույցը](support.md) կամ գրեք `surenakar@gmail.com`։ Հայերեն եզրաբանության բարելավման առաջարկները ողջունելի են։
